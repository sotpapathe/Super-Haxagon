# SuperHaxagon for the Sony PlayStation Portable

SuperHaxagon is a cross-platform, open source [Super Hexagon](http://superhexagon.com/) clone.

You can obtain a free copy of the source code licensed under the GPLv3 at:

https://github.com/RedTopper/Super-Haxagon

## Install

1. Download and extract `SuperHaxagon-PSP.zip`.
2. Copy the extracted `SUPERHAXAGON` directory into `PSP/GAME/` in your Memory
   Stick.
3. Launch the game from “Game” → “Memory Stick” in the main PSP menu.

If you want to change the title screen music, you can place any Ogg file in
your Memory Stick at `PSP/GAME/SUPERHAXAGON/USER/title.ogg`.
