# PSP Driver

This driver is for all versions of the Sony PlayStation Portable, without
needing custom firmware for starting the game. It uses stb for font loading and
libvorbisfile for music loading.

It also works on the [PPSSPP emulator](https://www.ppsspp.org/). It requires
setting the audio synchronization mode to “Smooth” to avoid distortion.
